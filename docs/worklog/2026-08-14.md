## 4. 캘리브레이션(실측 보정) 바

배경: 기존에는 300px 고정 기준 막대의 실제 길이를 자로 읽어 입력하는 방식이었는데, 눈금을 눈으로 읽는 오차(+ 자와 화면 간 시차)로 보정 오차가 커진다는 피드백 발생.

- **기준 막대를 드래그(또는 화살표 키, Shift=10px 단위)로 조절**하는 방식으로 전환: 실물에 눈으로 맞춰 막대 길이를 조정 → 그 실제 길이(mm)만 입력. "실물 크기로 보기" 모드는 실제 축척으로 작게 렌더링되므로 캔버스 컨테이너를 중앙 정렬 (`89224f5`)
- 드래그 핸들이 막대의 정확한 끝단(edge marker)을 가려서 정렬 기준점을 알아보기 어려웠던 문제 → **핸들과 정밀 엣지 마커를 분리**, 얇은 안내선으로 연결 (`a67efa4`)
- "실물 크기로 보기" 모드에서 휠 줌이 캔버스 렌더 크기를 의미 없이 흔들던 문제 → **해당 모드에서 휠 줌 비활성화**. 그리드 주요선을 실제 자 눈금처럼 10칸(10cm)마다 표시 (기존 5cm) (`5bfa2d6`, 여기서 엣지 마커가 막대 마지막 1px을 가리던 문제도 같이 수정)
- 엣지 마커/핸들을 절대좌표 오버레이 + 수기 픽셀 오프셋으로 구현했던 것이 여전히 막대 일부를 가리는 문제가 있어, **일반 문서 흐름(plain flow) 기반으로 재구현**: 엣지 마커는 막대 자신의 오른쪽 보더(`box-sizing: border-box`로 폭이 정확히 `barPx`)로, 핸들은 그 아래 별도 행에 마진으로 배치 → 구조적으로 겹칠 수 없게 함 (`efb870c`)
